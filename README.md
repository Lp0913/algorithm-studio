# 志通达算法研发工作室

展示计算机视觉、遥感分析与算法研发能力的静态网站。当前版本采用银白、冰蓝色科技视觉，通过点击导航切换页面内容，所有视图共享 `index.html` 一个入口。

网站由原生 HTML、CSS 和 JavaScript 实现。运行时无需框架或后端；构建脚本使用 Node.js 内置模块，不需要安装 npm 依赖。

## 构建与本地预览

在项目目录执行构建：

```sh
node build-app.cjs
```

然后启动本地服务器：

```sh
python3 tools/preview-server.py
```

浏览器打开 [本地预览](http://127.0.0.1:8856/)。发布到 GitHub Pages 时，根目录的 `index.html` 和所引用的脚本、样式、素材需要一同提交。Hash 路由不需要服务端重写规则。

## 单入口与导航

| 视图 | 地址片段 | 内容 |
| --- | --- | --- |
| 首页 | `#/home` | 明亮科技封面、算法定位与导航入口 |
| 算法目录 | `#/algorithms/0` | 六类方向，按分类点击查看算法和对应效果 |
| 动态演示 | `#/demos` | 10 部本地视频，可切换播放 |
| 关于我们 | `#/about` | 工作室介绍与返回其他视图的导航 |

不带 hash 时进入首页。目录分类编号为 `0` 到 `5`：地物提取、检测与追踪、时空变化、影像处理、农林生态、安全与质检，共 35 项算法。

具体算法可直接分享，例如 `#/algorithms/1/1-4` 打开“车辆追踪”。浏览器前进、后退可在路由之间切换。每个分类保留可见的算法名称、用途与缩略图，点击后更新该分类的效果区域；网站不依赖向下浏览整站长页来进入其他视图。

旧的 `algorithms.html` 仅作为兼容跳转入口，会保留 hash 并返回主入口。`#cap-panel-N`、`#cap-tab-N` 和 `#algorithm-N-M` 等受支持的旧链接仍可定位分类或算法。

## 动效与交互

- 首页默认展示点云重建，每 11 秒按“点云重建 → 遥感解析 → 目标追踪”自动轮换，标题、说明、图例与画面一起更新。点击场景立即切换并重新计时，底部细线显示本幕进度。遥感解析展示俯视地物分类；追踪展示目标与轨迹；点云重建展示散点聚合成三维结构。这些是算法视觉示意，不是在线模型推理。
- 首页不再显示暂停按钮。离开首页、页面进入后台或使用键盘聚焦首页内容时暂停自动轮换；系统开启“减少动态效果”时停止自动动画与轮换，手动选择仍显示完整静态结果。点云重建为首页概念演示，未新增目录中的算法项目或实测案例。
- 对比效果可拖动分界线，也可使用键盘方向键操作。
- 动态演示播放实际本地 MP4 文件；10 个选项全部展开，无列表内部滚动条。桌面与手机采用两列，平板采用五列。窄屏选择后自动定位播放器。离开视图或切到后台时暂停，手动暂停状态会保留。
- 导航、移动端菜单和算法选择提供键盘操作、焦点状态与选中状态。

## 主要文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 构建生成的唯一正式页面入口，含四个视图与目录数据 |
| `build-app.cjs` | 总构建入口，组合页面、路由入口和明亮主题 |
| `build-home.cjs` | 历史首页模板，不用于当前总构建 |
| `build-chapters.cjs` | 历史章节模板，不用于当前总构建 |
| `catalog-render.js` | 构建与浏览器共用的算法、效果图和对比组件渲染逻辑 |
| `app.js` | Hash 路由、前进后退、视频状态、菜单、对比与首屏动效 |
| `hero-motion.js` | 地物分类、目标追踪、点云重建场景的实时绘制与生命周期 |
| `tools/preview-server.py` | 本地预览服务，支持视频分段加载并禁用预览缓存 |
| `studio.css` | 基础样式、算法目录与对比组件布局 |
| `home.css` | 科技封面、演示区和介绍区布局 |
| `app.css` | 单入口各视图布局与移动端适配 |
| `light-theme.css`、`studio-system.css`、`hero-motion.css` | 当前银白、冰蓝色主题覆盖 |
| `assets/chapter-design/catalog.json` | 六类 35 项算法及 10 部视频的内容数据 |
| `assets/chapter-design/catalog-audit.json` | 素材尺寸、语义限制和裁剪建议 |
| `assets/chapter-design/` | 当前封面、对比示意图、素材生成记录及图标 |
| `assets/algorithm-effects/` | 算法效果图片、引用信息和许可证 |
| `assets/github/` | 本地演示视频、封面图、来源记录和许可证 |

当前入口加载 `catalog-render.js`、`hero-motion.js` 与 `app.js`。仓库中的 `studio.js`、`home.js` 等历史脚本不属于当前入口的运行逻辑。

## 内容维护

修改算法名称、用途、输入输出或视频信息时，优先编辑 `assets/chapter-design/catalog.json`，再运行 `node build-app.cjs`。保持 `0-0`、`1-4` 等算法 ID 稳定，避免已有分享链接失效。新增或删除项目时同步调整页面中的总数文案。

修改页面结构时编辑构建模板及 `catalog-render.js`；不要只改生成的 `index.html`，因为下次构建会覆盖它。只修改 `app.js` 或样式文件时无需重新生成 HTML；对外发布前应统一运行总构建确认输出。

当前未填写邮箱、微信、电话号码等联系方式，也没有提交需求或发送消息的后台接口。后续提供真实联系方式后，再在导航或介绍视图的模板中添加。

## 素材说明

`assets/chapter-design/hero-tech-light.jpg` 为首页概念视觉。`field-before.jpg` 与 `field-after.jpg` 用于标明“效果示意”的地块对比。相关生成记录保留在同目录的 JSON 文件中；这些概念或示意素材不代表实际测绘结果、客户项目或模型指标。

算法效果图和视频保留原始来源、许可与必要说明，记录位于素材目录的 JSON、`NOTICE.md`、`notices/` 和 `licenses/` 中。维护或分发时保留这些文件。双期遥感影像是观测对照，树种分类图与病叶热图也应按其实际含义展示；不要将它们误标为其他算法的实测结果。

本轮统一了首页、算法目录和动态演示的无衬线字体、冰蓝色调、导航和工作区样式。`hero-motion.js` 独立管理动画、暂停、隐藏与减少动态设置；首屏之外不持续渲染。
